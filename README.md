# Kepler Atlas

Interaktive Visualisierung der Keplerschen Gesetze für ein Erklärungsvideo.

## Inhalte

- Ellipse, Brennpunkte, große und kleine Halbachse sowie Exzentrizität
- Erstes Keplersches Gesetz
- Zweites Keplersches Gesetz und Auswirkungen auf die Jahreszeiten
- Drittes Keplersches Gesetz als Verhältnis von Umlaufzeit und Bahnhalbachse
- Anwendungen: Zentralkörpermasse, geostationäre Satelliten und Exoplaneten

## Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
